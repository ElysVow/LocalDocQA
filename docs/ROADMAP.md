# 路线图

## v0.1（已完成）

- [x] 多格式解析：PDF（保留页码）、DOCX（含表格）、Markdown、TXT、LOG、CSV、JSON、HTML
- [x] 中文友好的递归切分，块间保留重叠
- [x] 基于 SHA256 的入库去重，支持 `--force` 重建
- [x] numpy 自建向量库，一个集合一个目录，原子写入
- [x] Ollama 语义向量 + 离线哈希向量自动降级
- [x] 带 `[编号]` 引用的问答，流式与非流式两种输出
- [x] Streamlit 界面：集合管理、上传、进度、来源展开、对话导出、检索调试
- [x] 命令行：`ingest` / `ask` / `search` / `list` / `stats` / `check`
- [x] 检索评估脚本与 8 题评估集
- [x] 48 项 pytest（含 AppTest 界面冒烟）、ruff、GitHub Actions

## v0.2（界面与知识库管理，已完成）

- [x] 问答页重做：空态一句引导 + 三个文字示例、重新生成上一条回答、复制回答、Markdown 导出
- [x] 来源可读性：按查询与原文的共有短语高亮，每段可展开原文
- [x] 对话按集合落盘，刷新/重启/切集合后仍能恢复
- [x] 知识库管理：文档详情三标签、逐文件入库报告、集合 zip 导出与导入
- [x] 设置页：配置表、模型探测缓存、数据占用统计、批量清理对话
- [x] 69 项 pytest（新增 text_utils / conversations / archive 三组）、ruff 全绿

## v0.3（质量）

- [ ] 扫描版 PDF 的 OCR 兜底（PaddleOCR，按页检测文字层是否为空）
- [ ] 评估集扩充到 50+ 问题，覆盖每份示例文档与真实论文各 3~5 题
- [ ] BM25 + 向量混合检索（RRF 融合），主要解决缩写、编号、专有名词召回
- [ ] 引入交叉编码器 rerank（可选依赖，默认关闭）
- [ ] 回答置信度提示：最高分低于阈值时，明说"资料相关性弱"
- [ ] 支持"逐文档对比"：同一问题分别召回 2~3 份文档的片段并排放
- [ ] 评估报告进 CI：hit@5 低于基线（当前 0.875）时让流水线失败

## v1.0（分发）

- [ ] Windows 便携包（PyInstaller + 启动 bat，双击即用，免装 Python）
- [ ] 多语言界面（中/英）
- [ ] 文档变更检测：同路径文件哈希变化时提示"该文档已更新，是否重建索引"
- [ ] 插件式 loader 注册表，允许用户自己加格式解析器

## 明确不做

- 不做云端同步、账号体系：定位是"本机工具"，引入账号就开始涉及数据托管。
- 不做通用聊天：没有检索结果的对话不做兜底生成，避免把模型幻觉包装成"文档问答"。
- 不追求支持所有格式：Excel、PPT 的解析交给专门的库，需要时再按 loader 扩展点接入。
